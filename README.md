# dungeo-ai-adventure
Angular RPG app with a backend API. Create characters, generate AI avatars with Gemini, and play AI-generated story sessions with branching choices and dynamic world-building. WIP.

try it!: https://dungeeoo.web.app

Local quick start

## Structure
- /frontend (Ionic + Angular (TypeScript))
- /backend (API server (Node.js) + Gemini integration)

## Quick start
1) Frontend
   - cd frontend
   - npm install
   - ionic serve

2) Backend
   - cd backend
   - npm install
   - npm run dev
